IEC

International Electrotechnical Commission

https://www.iec.ch/homepage

IEC — ЩО ЦЕ?

  • Міжнародна електротехнічна комісія — заснована 1906 р., Женева
  • Охоплює 173 країни
  • Україна — член з 1993 року (представник: ДП «УкрНДНЦ»)
  • Напрямки: електрика, електроніка, електромагнетизм
  • Основний внесок для ПЗ — стандарти серії IEC/ISO 25000 та IEC 62443 (кібербезпека)

ДСТУ — ЩО ЦЕ?

ДСТУ — Державний стандарт України. Технічні нормативи, прийняті як національні стандарти на основі міжнародних (ISO, IEC, IEEE).

ДСТУ ISO/IEC 25022:2019

SQuaRE — Software product Quality Requirements and Evaluation

Інженерія систем і програмних засобів. Вимоги до якості та оцінювання. Вимірювання якості під час застосування.

  • Результативність — чи вирішує продукт задачу користувача
  • Ефективність — витрати ресурсів для досягнення мети
  • Задоволеність — зручність та позитивний досвід
  • Безризиковість — вплив на здоров'я, безпеку, економіку
  • Покриття контексту — застосовність у різних умовах

https://uas.org.ua/ua/standart/dstu-iso-iec-25022-2019/

ДСТУ ISO/IEC 14598-6:2005

Інформаційні технології. Оцінювання програмного продукту

Частина 6 — Документація модулів оцінювання

  • Визначає вимоги до документування процесу оцінювання ПЗ
  • Описує структуру модулів оцінювання (evaluation modules)
  • Використовується при сертифікації та аудиті програмних продуктів
  • Базується на серії ISO/IEC 14598 — 6 частин стандарту

https://uas.org.ua/ua/standart/dstu-iso-iec-14598-6-2005/

ДСТУ ISO/IEC/IEEE 15939:2018

Інженерія систем і програмних засобів. Процес вимірювання

Стандарт визначає концептуальну модель і термінологію для вимірювань у програмній інженерії.

Модель вимірювання

Процес

Планування → Збір → Аналіз → Комунікація

ISO

International Organization for Standardization

https://www.iso.org/about-us.html

ISO — ЩО ЦЕ?

  • Міжнародна організація зі стандартизації — заснована 1947 р., Женева
  • 167 національних органів стандартизації
  • Понад 24 000 стандартів у всіх галузях
  • Не урядова організація — членство через нац. органи (в Україні — ДП «УкрНДНЦ»)

Ключові ISO-стандарти для ПЗ

  • ISO 9001 — система менеджменту якості
  • ISO/IEC 27001 — інформаційна безпека (ISMS)
  • ISO/IEC 12207 — процеси життєвого циклу ПЗ
  • ISO/IEC 25000 (SQuaRE) — якість ПЗ

TC39

Specifying JavaScript

https://tc39.es/

TC39 — ЩО ЦЕ?

Технічний комітет 39 (TC39) — підрозділ ECMA International, що підтримує та розвиває специфікацію JavaScript (ECMAScript).

  • Учасники: Google, Mozilla, Apple, Microsoft, Meta та незалежні розробники
  • Нові пропозиції публічно обговорюються на GitHub
  • Зустрічі кожні 2 місяці; рішення через консенсус
  • Специфікація: https://tc39.es/ecma262/

TC39 — ПРОЦЕС ПРОПОЗИЦІЙ

Кожна нова функція JavaScript проходить 5 стадій:

Stage 0 — Strawperson

Початкова ідея, без формальних вимог

Stage 1 — Proposal

Є champion, описана задача та рішення

Stage 2 — Draft

Початковий текст специфікації

Stage 3 — Candidate

Повна специфікація, готова до реалізації у браузерах

Stage 4 — Finished

Включена до наступного видання ECMAScript

ECMA INTERNATIONAL

Організація зі стандартизації інформаційних та комунікаційних систем, заснована 1961 р. у Женеві.

  • ECMA-262 — специфікація ECMAScript (JavaScript)
  • ECMA-404 — формат JSON
  • ECMA-334 — специфікація C#
  • ECMA-335 — CLI (Common Language Infrastructure, .NET)

https://www.ecma-international.org/

W3C

World Wide Web Consortium

https://www.w3.org/

W3C — ЩО ЦЕ?

  • Заснований 1994 р. Тімом Бернерсом-Лі (MIT, CERN)
  • Понад 400 організацій-членів
  • Розробляє відкриті стандарти вебу — через Working Groups

Ключові стандарти W3C

  • HTML — структура вебсторінок
  • CSS — стилізація
  • SVG — векторна графіка
  • ARIA — доступність (accessibility)
  • WebAssembly — виконання коду у браузері
  • XML, XPath, XSLT — обробка даних

W3C VALIDATOR

Інструмент перевірки валідності HTML та CSS

Перевіряє, чи відповідає розмітка специфікаціям W3C. Допомагає уникати:

  • Помилок синтаксису HTML
  • Проблем сумісності між браузерами
  • Порушень доступності (accessibility)
  • SEO-проблем, пов'язаних з некоректною розміткою

https://validator.w3.org/

https://jigsaw.w3.org/css-validator/

НАВІЩО СЕРТИФІКУВАТИСЯ?

Ще немає досвіду?

  • Сертифікат — перший сигнал рекрутеру до першого місця роботи
  • Підтверджує самонавчання та мотивацію
  • Відкриває двері до стажування
  • Конкретна перевага у резюме серед однокурсників

Довгострокова цінність

  • Систематизація знань із практикою
  • LinkedIn-бейдж — видимий HR-спеціалістам
  • Умова для участі у партнерських програмах (Microsoft, AWS)
  • Часто — підвищення зарплати після отримання

SCRUM / AGILE СЕРТИФІКАЦІЇ

Найшвидший спосіб отримати підтвердження компетентності — актуально для командної роботи в будь-якому напрямку.

Scrum.org

  • PSM I — Professional Scrum Master I
  • PSPO I — Professional Scrum Product Owner I
  • Обидва: $150 / ~6 300 грн
  • Без обов'язкового тренінгу — можна самостійно
  • Безстроковий (не закінчується)

Scrum Alliance

  • CSM — Certified ScrumMaster
  • CSPO — Certified Scrum Product Owner
  • Потребує 2-денного тренінгу
  • Дорожче, але ширше визнаний у корпоративному секторі
  • Дійсний 2 роки

https://www.scrum.org/professional-scrum-certifications
