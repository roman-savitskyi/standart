IEC — WHAT IS IT?

  • International Electrotechnical Commission — founded 1906, Geneva
  • Covers 173 countries
  • Focus: electricity, electronics, electromagnetism
  • Key contribution for software — IEC/ISO 25000 series and IEC 62443 (cybersecurity)

ISO — WHAT IS IT?

  • International Organization for Standardization — founded 1947, Geneva
  • 167 national standards bodies
  • Over 24,000 standards across all industries
  • Non-governmental — membership through national bodies

Key ISO standards for software

  • ISO 9001 — quality management systems
  • ISO/IEC 27001 — information security (ISMS)
  • ISO/IEC 12207 — software lifecycle processes
  • ISO/IEC 25000 (SQuaRE) — software quality

ISO — NEDİR?

  • Uluslararası Standardizasyon Örgütü — 1947'de kuruldu, Cenevre
  • 167 ulusal standart kuruluşu
  • Tüm sektörlerde 24.000'den fazla standart
  • Hükümet dışı kuruluş — ulusal kuruluşlar aracılığıyla üyelik

Yazılım için temel ISO standartları

  • ISO 9001 — kalite yönetim sistemleri
  • ISO/IEC 27001 — bilgi güvenliği (BGYS)
  • ISO/IEC 12207 — yazılım yaşam döngüsü süreçleri
  • ISO/IEC 25000 (SQuaRE) — yazılım kalitesi

TC39 — WHAT IS IT?

Technical Committee 39 (TC39) — a subgroup of ECMA International that maintains and develops the JavaScript (ECMAScript) specification.

  • Members: Google, Mozilla, Apple, Microsoft, Meta and independent developers
  • New proposals are publicly discussed on GitHub
  • Meetings every 2 months; decisions by consensus
  • Specification: https://tc39.es/ecma262/

TC39 — NEDİR?

Teknik Komite 39 (TC39) — JavaScript (ECMAScript) spesifikasyonunu geliştiren ECMA International'ın bir alt grubu.

  • Üyeler: Google, Mozilla, Apple, Microsoft, Meta ve bağımsız geliştiriciler
  • Yeni teklifler GitHub'da kamuya açık tartışılır
  • Her 2 ayda bir toplantı; kararlar uzlaşı ile alınır
  • Spesifikasyon: https://tc39.es/ecma262/

TC39 — PROPOSAL PROCESS

Every new JavaScript feature goes through 5 stages:

Stage 0 — Strawperson

Initial idea, no formal requirements

Stage 1 — Proposal

Has champion, problem and solution described

Stage 2 — Draft

Initial specification text

Stage 3 — Candidate

Full specification, ready for browser implementation

Stage 4 — Finished

Included in the next ECMAScript edition

TC39 — TEKLİF SÜRECİ

Her yeni JavaScript özelliği 5 aşamadan geçer:

Aşama 0 — Strawperson

İlk fikir, resmi gereksinim yok

Aşama 1 — Teklif

Sorumlusu var, sorun ve çözüm tanımlandı

Aşama 2 — Taslak

Spesifikasyon metni başladı

Aşama 3 — Aday

Tam spesifikasyon, tarayıcı uygulamasına hazır

Aşama 4 — Tamamlandı

Bir sonraki ECMAScript sürümüne dahil edildi

W3C — WHAT IS IT?

  • Founded 1994 by Tim Berners-Lee (MIT, CERN)
  • Over 400 member organizations
  • Develops open web standards through Working Groups

Key W3C Standards

  • HTML — web page structure
  • CSS — styling
  • SVG — vector graphics
  • ARIA — accessibility
  • WebAssembly — code execution in browser
  • XML, XPath, XSLT — data processing

W3C — NEDİR?

  • 1994'te Tim Berners-Lee tarafından kuruldu (MIT, CERN)
  • 400'den fazla üye kuruluş
  • Çalışma Grupları aracılığıyla açık web standartları geliştirir

Temel W3C Standartları

  • HTML — web sayfası yapısı
  • CSS — stil
  • SVG — vektör grafikleri
  • ARIA — erişilebilirlik
  • WebAssembly — tarayıcıda kod çalıştırma
  • XML, XPath, XSLT — veri işleme

QA / TESTING

International standard — ISTQB (International Software Testing Qualifications Board). Recognized in over 120 countries.

Foundation Level (CTFL)

  • Basic certification — no experience required
  • Covers: test design, test management, testing techniques
  • Cost: ~$250 (varies by country)
  • Required before Advanced level

Extensions and Advanced

  • ISTQB Agile Tester — for Agile teams (after CTFL)
  • Advanced Test Analyst — requires experience
  • Advanced Test Manager — requires experience
  • Available via ISTQB member boards worldwide

https://www.istqb.org/

KALİTE GÜVENCE / TEST

Uluslararası standart — ISTQB (Uluslararası Yazılım Test Yeterlilikleri Kurulu). 120'den fazla ülkede tanınmaktadır.

Temel Seviye (CTFL)

  • Temel sertifikasyon — deneyim gereksinimi yok
  • Kapsam: test tasarımı, test yönetimi, test teknikleri
  • Maliyet: ~$250 (ülkeye göre değişir)
  • İleri seviye öncesi zorunlu

Uzantılar ve İleri Seviye

  • ISTQB Agile Tester — Agile ekipler için (CTFL sonrası)
  • Advanced Test Analyst — deneyim gerektirir
  • Advanced Test Manager — deneyim gerektirir
